# Instruction for Uploading Files

1. Go to Catalog tab and find the 'bronze' schema under the  catalog name 'dunnhumby_project'  

2. Click create and select the 'table'. You will be redirected to the Data Ingestion tab. 

3. Individually drag and drop each file and wait for complete upload. It will automatically create table name and click 'Create table'

4. Repeat the process 2 and 3 for each file. All the 8 tables must be uploaded

1. campaign_desc
2. campaign_table
3. causal_data
4. coupon
5. coupon_redempt
6. hh_demograpics

8. transaction_data
